Every identifier in this module wraps a non-empty `String` with no further
invariant. They are generated by a shared `id_newtype!` macro so the seven
types have byte-identical structure (`new`, `as_str`, `Display`, transparent
serde, a per-type `Invalid*` thiserror struct) while remaining distinct
types — passing a `MessageId` where a `RequestId` is expected is a compile
error.

# Schema

Generated types: `MessageId`/`InvalidMessageId`,
`OrganizationId`/`InvalidOrganizationId`, `RequestId`/`InvalidRequestId`,
`StopSequence`/`InvalidStopSequence`, `ToolName`/`InvalidToolName`,
`ToolUseId`/`InvalidToolUseId`, `UserId`/`InvalidUserId`.

Each `$name`:
```rust
pub struct $name(String); // #[serde(transparent)]
pub struct $err;          // "<Name> must not be empty"
impl $name {
    pub fn new(s: impl Into<String>) -> Result<Self, $err>;
    pub fn as_str(&self) -> &str;
}
impl std::fmt::Display for $name { ... }
```

# Examples

```rust
use clauders::types::RequestId;
let rid = RequestId::new("req_abc123").unwrap();
assert_eq!(rid.as_str(), "req_abc123");
```
